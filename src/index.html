Objetivo

Controles

Mover Saltar Agacharse Bloquear Punetazo rapido Patada larga Ataques aereos Especial: requiere barra llena y consume energia Pausar o reanudar

Consejos

  • El bloqueo reduce el impacto pero te deja quieto.
  • El punetazo es mas rapido; la patada llega mas lejos.
  • Si la CPU se acerca demasiado, retrocede y castiga con patada.
